# Ders İçeriklerinden Otomatik Çoktan Seçmeli Soru Oluşturma Sistemi

React, TypeScript ve Vite ile hazırlanmış Türkçe başlangıç sayfası.

## Gerekenler

- Node.js (npm ile birlikte gelir)

Node.js, JavaScript uygulamalarını bilgisayarınızda çalıştıran programdır. Kurduktan sonra yeni bir terminal açın.

## İlk kurulum ve çalıştırma

Proje klasöründe şu komutları sırayla çalıştırın:

```powershell
npm.cmd install
npm.cmd run dev
```

Windows PowerShell kullanıyorsanız `npm.cmd` yazın. Terminalde gösterilen yerel adresi (çoğunlukla `http://localhost:5173`) tarayıcınızda açın. `npm.cmd install`, projenin ihtiyaç duyduğu paketleri indirir. `npm.cmd run dev`, geliştirme sunucusunu başlatır. Durdurmak için terminalde `Ctrl + C` tuşlarına basın.

## Bu sürümde

Dosya seçimi ve sürükleyip bırakma, PDF/DOCX/PPTX tür kontrolü, soru sayısı ve zorluk seçimi çalışır. Dosya sunucuya gönderilmez ve soru üretimi henüz bağlı değildir; düğmeye basınca bu durum sayfada açıklanır.
